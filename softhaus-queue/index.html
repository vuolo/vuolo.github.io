After the composer opens, paste the caption if it is not already there. The intent link also cannot attach these images. Use the Shortcut (or save the four pictures and add them yourself) for that.

iPhone Shortcut

The fastest path is the Add Shortcut button above. After it is added, open X and switch to @softhaus_, then run softhaus post v5. In the share sheet choose X, paste the caption, post, then confirm the delete prompt so the four Recents copies are removed.

If the import link does not work, you can build the same shortcut by hand in about a minute:

  1. Open Shortcuts, tap +, name it softhaus post v5.
  2. Add Get Contents of URL for https://vuolo.github.io/softhaus-queue/caption.txt, then Copy to Clipboard.
  3. Add a List of the four image URLs (01.jpg through 04.jpg on this page), then Repeat with Each: Get Contents of URL, Get Images from Input, Convert Image to JPEG, Add to Variable Images.
  4. After the loop, Get Variable Images and Save to Photo Album (Recents).
  5. Add Get Latest Photos (4) and Set Variable PhotosToDelete to that result.
  6. Add the system Share action with those photos (images only). Choose X, then paste the caption.
  7. After Share, add Delete Photos using PhotosToDelete. iOS will ask you to confirm.

A signed import file is at softhaus post v5.shortcut.
