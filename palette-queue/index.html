Post on X

The Post button and the iPhone Shortcut cannot pick the account. X always uses whichever account is currently active in the app. Open X first and switch to Palette Diary, then come back and post. After the composer opens, paste the caption if it is not already there. The intent link also cannot attach these images. Use the Shortcut (or save the four pictures and add them yourself) for that.

iPhone Shortcut

Make this once in the Shortcuts app. It reads today.json, copies the caption, downloads the four images, and opens the share sheet so you can send them to X.

  1. Open Shortcuts, tap +, name it Palette Diary post.
  2. Add Get Contents of URL. Set the URL to https://vuolo.github.io/palette-queue/today.json.
  3. Add Set Variable. Name: Post. Value: the URL contents (the JSON).
  4. Add Get Dictionary Value. Key: caption. Dictionary: Post.
  5. Add Copy to Clipboard. Input: that caption value.
  6. Add Get Dictionary Value. Key: images. Dictionary: Post.
  7. Add Repeat with Each on the images list.
    1. Inside the loop, add Get Contents of URL. URL: Repeat Item.
  8. After the loop, add Share. Input: Repeat Results (the four images). When the sheet opens, choose X.
  9. Optional: add a Show Notification that says "Caption is on your clipboard. Paste it, and make sure Palette Diary is the active account."

If Get Contents of URL returns text instead of a dictionary, add Get Dictionary from Input after step 2, then use that dictionary as Post.

A signed .shortcut file is not included. Apple signs those on a Mac or iPhone, and an unsigned file usually will not import.
