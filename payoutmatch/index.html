The gap

What beats Stripe’s free single-platform report

Stripe’s Dashboard report reconciles payouts on Stripe. payoutmatch is built for the three jobs that report does not do.

1

An MCP endpoint assistants call directly

Ask Claude or Cursor to list payouts, explain one, or match a bank CSV. No Dashboard tab, no copy-paste. The four tools run over stdio MCP today.

2

Bank matching and bookkeeper-ready journals

match_deposits pairs payouts to real bank rows and flags amount or date misses. export_journal writes a balanced CSV, QuickBooks, or Xero journal — debits equal credits.

3

Multi-rail, starting with Stripe

Stripe is live in the MCP now (mock fixtures by default; test-mode adapter wired). Shopify and PayPal are on the roadmap and are not live.

The MCP tools

        
Four tools, live in the local server today

        
These are the registered tool names in the MCP server. Names and arguments below match the prototype — nothing invented.

      

      

        

          
list_payouts

          
Optional from, to as YYYY-MM-DD

          
Lists payouts by arrival date, with amount, currency, and status (paid, pending, in_transit, canceled, failed).

        

        

          
explain_payout

          
payout_id, optional include_lines

          
Breaks a payout into gross charges, fees, refunds, disputes, adjustments, other, and net. Sets verified when net equals the payout amount, and warns on FX or gaps.

        

        

          
match_deposits

          
bank_csv_path (date, description, amount)

          
Matches payouts to bank deposits. Returns matched rows plus unmatched payouts and bank lines, with reasons such as amount off, outside the date window, missing, or not Stripe.

        

        

          
export_journal

          
payout_id, format of csv, qbo, or xero

          
Exports a journal entry for the payout. Debits must equal credits; any unexplained difference is booked to Stripe Clearing.

Live in the MCP

Plug in locally

        
Point Claude Desktop or Cursor at the server

        
Add this to claude_desktop_config.json or ~/.cursor/mcp.json, then ask: “List my payouts in October and explain the biggest one,” or “Match payouts against this bank CSV.”

      

      
{
  "mcpServers": {
    "payoutmatch": {
      "command": "npx",
      "args": ["tsx", "/ABSOLUTE/PATH/payoutmatch/src/server.ts"]
    }
  }
}

      
The server uses a read-only restricted key for Stripe. The prototype does not store payout data server-side beyond a local usage counter for the free-tier stub.
